A WhatsApp API you own.

wa-gateway holds the WhatsApp sessions for your bots and exposes them as a plain HTTP API — the same endpoints, request bodies and webhook payloads whapi.cloud speaks. Point an existing bot at it by changing one environment variable.

Link a number in about a minute

  1. Open the console and enter your management key.
  2. Add a number — an id, and the webhook URL your bot listens on.
  3. Scan the QR with WhatsApp → Settings → Linked devices. Your number now shows wa-gateway as a linked device, exactly like WhatsApp Web.
  4. Copy the token into your bot. That token is what selects this number.

Prefer not to scan a screen? Set a pairing phone on the number and the console shows an 8-character code for Link with phone number instead.

What it does

Drop-in for whapi.cloud

Same paths, same bodies, same response shapes, same webhook events. Migrating an existing bot is a base-URL change and a token swap — not a rewrite.

Many numbers, one service

Each number is its own session with its own token, webhook target, rate limit and credentials. A bot sends its token and reaches its own number. Nothing is shared.

Send and receive

Text, images, native polls with live vote tallies, emoji reactions, read receipts and typing indicators out. Text, images, GIFs, voice notes, audio and link previews in — media downloaded, decrypted and re-hosted for you.

Groups that make sense

Authoritative rosters and subjects on demand, with participant identities resolved back to real phone numbers rather than WhatsApp's newer opaque LIDs.

Ordered, retried delivery

Inbound events are delivered to your webhook one at a time, in order, and retried on failure. Conversation threading doesn't get corrupted by a slow endpoint.

Survives redeploys

Session credentials live in the database, not the container filesystem. Ship a new version and your numbers stay linked — no re-scanning anything.

Worth knowing

This drives WhatsApp through an unofficial client, which is against WhatsApp's terms of service. It's built for running your own bot on your own number in your own groups — the lowest-risk profile there is — and every number carries an outbound rate cap so a bug can't turn into a ban. Don't point it at cold outreach.
